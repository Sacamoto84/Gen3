# Скриптовая система Gen3

Скрипт — это текстовый файл на SD-карте: одна строка — одно действие на панели генератора. Скрипт выполняется в фоне (кооперативная многозадачность), поэтому меню, энкодер и экран генератора продолжают работать без блокировки.

```text
CH1 CR ON
DELAY 2000
CH1 CR OFF
DELAY 2000
GOTO 1
```

Выход две секунды включён, две секунды выключен, затем `GOTO 1` возвращает на первую строку. Скрипт выполняется циклически, пока его не остановят.

---

## 1. Запуск и управление

1. Положите файл с расширением `.txt` в папку `/script` на SD-карте. Карту можно подключить кардридером или через пункт настроек **«USB MSD»**. В имени допускаются латинские буквы, цифры и символ `_`, длина до 14 символов.
2. На главном экране удержите кнопку энкодера — откроются настройки.
3. Выберите **«Скрипт»**, затем нужный файл. Скрипт запустится, и откроется главный экран.

### Пункты меню настроек

| Пункт настроек | Назначение |
|---|---|
| **«Скрипт»** | Список файлов из `/script`, клик запускает выбранный файл |
| **«Скрипт вид»** | Показывает скрипт, подсвечивает текущую выполняемую строку, внизу отображает значения используемых регистров. Энкодер листает строки, клик выходит или продолжает команду `WAIT`, удержание открывает редактор |
| **«Скрипт Stop»** | Останавливает скрипт. Сигнал не выключается: генератор остаётся в последнем состоянии |
| **«Редактор»** | Встроенный редактор скрипта энкодером прямо на устройстве (см. [Редактор на устройстве](#редактор-на-устройстве)) |

> [!NOTE]
> Если на карте памяти отсутствует сохранённая конфигурация `/Config/ch1.ini`, при включении устройства автоматически загружается и запускается `/script/load_def.txt`.

### Поведение при смене режимов

* На экранах **«Фильтр»**, **«Видео»** и **«BT Audio»** выполнение скрипта приостанавливается и продолжается после возврата.
* Пункты **«Плеер»** и **«USB MSD»** передают управление другой прошивке/режиму, и скрипт на этом завершается.

## 2. Формат файла и ограничения

* **Одна команда на строку**, параметры разделены пробелами.
* **Регистр букв важен**: команды пишутся заглавными буквами (`DELAY`, а не `delay`).
* **Нумерация строк**: порядковый номер в файле, считая с 1. Пустая строка занимает номер и ничего не делает.
* **Длина строки**: до 22 байт (остальное отсекается). Русская буква в кодировке UTF-8 занимает 2 байта.
* **Максимум строк в файле**: до 127 строк (`PC_MAX = 128`, нулевой индекс занят именем скрипта).
* **Числа с плавающей точкой**: дробная часть пишется через точку: `10.5`.
* **Регистры**: доступно 10 регистров `F0`..`F9` (тип `float`). При каждом запуске скрипта они инициализируются нулями.
* В описании команд ниже `x` означает либо константу, либо регистр (например, `CR1 FR 1000` и `CR1 FR F1` эквивалентны).

## 3. Система команд

### А. Управление генератором

| Команда | Описание | Диапазон в редакторе |
|---|---|---|
| `CH1 CR ON`, `CH1 CR OFF` | Включение / выключение выхода несущей | |
| `CH1 AM ON`, `CH1 AM OFF` | Включение / выключение амплитудной модуляции (AM) | |
| `CH1 FM ON`, `CH1 FM OFF` | Включение / выключение частотной модуляции (FM) | |
| `CR1 FR x` | Частота несущей, Гц (целые 0..65535) | 200..10000 |
| `CR1 MOD имя` | Форма несущей из `/Carrier/имя.dat` | Выбор из списка файлов |
| `AM1 FR x` | Частота AM, Гц | 0.1..100 |
| `AM1 MOD имя` | Форма AM из `/Mod/имя.dat` | Выбор из списка файлов |
| `FM1 BASE x` | Центральная (базовая) частота FM, Гц (целые 0..65535) | 200..5000 |
| `FM1 DEV x` | Девиация FM, Гц | 0.1..5000 |
| `FM1 FR x` | Частота FM, Гц | 0.1..100 |
| `FM1 MOD имя` | Форма FM из `/Mod/имя.dat` | Выбор из списка файлов |

* Диапазоны из последнего столбца действуют только при вводе через редактор на приборе; в текстовом файле на SD-карте можно задавать любые допустимые прошивкой значения.
* Для `CR1 FR` и `FM1 BASE` дробная часть отбрасывается, значения за пределами диапазона `0..65535` ограничиваются.
* Имя формы сигнала должно быть не длиннее 14 символов.
* Пока включена FM (`CH1 FM ON`), центральную частоту задаёт `FM1 BASE`, и команда `CR1 FR` на выходной сигнал не влияет.
* Команды второго канала `CH2`, `CR2`, `AM2`, `FM2` оставлены для совместимости со старыми файлами и пропускаются без ошибки.

### Б. Работа с регистрами

| Команда | Описание |
|---|---|
| `LOAD F1 x` | `F1 = x` (запись числа или значения другого регистра) |
| `PLUS F1 x` | `F1 = F1 + x` |
| `MINUS F1 x` | `F1 = F1 - x` |
| `MUL F1 x` | `F1 = F1 * x` |
| `DIV F1 x` | `F1 = F1 / x` (деление на ноль останавливает скрипт) |
| `READ F1 <ПАРАМЕТР>` | Считывает текущее значение с панели прибора в `F1`. Доступно: `CR1 FR`, `AM1 FR`, `FM1 BASE`, `FM1 DEV`, `FM1 FR`. Позволяет скрипту реагировать на настройки, выставленные пользователем вручную |

> [!TIP]
> В экранном редакторе числа вводятся в диапазоне `0..99999.9` (для `MUL` и `DIV`: `0.001..99.999`). Отрицательное число задаётся через вычитание: сначала `LOAD F2 0`, затем `MINUS F2 50`.

### В. Управление ходом выполнения

| Команда | Описание |
|---|---|
| `GOTO n` | Переход на строку `n` (только фиксированное число, номер строки от 1) |
| `LOOP F0 n` | Вычитает 1 из регистра и переходит на строку `n`, пока значение больше нуля |
| `GOSUB n` | Вызов подпрограммы со строки `n` (вложенность до 4 уровней) |
| `RET` | Возврат из подпрограммы на строку, следующую за `GOSUB` |
| `IF F1 <op> x` | Условный переход. Если условие ложно, переходит к ветке `ELSE` или `ENDIF` |
| `ELSE` | Начало альтернативной ветки блока `IF` (необязательна) |
| `ENDIF` | Окончание условного блока `IF` |
| `DELAY x` | Пауза в миллисекундах (число или регистр). При `x <= 0` паузы нет |
| `WAIT` | Приостановка выполнения до клика пользователя в окне «Скрипт вид» |
| `YIELD` | Передача управления интерфейсу до следующего прохода цикла |
| `END` | Остановка выполнения скрипта |
| `T текст` | Комментарий (строка игнорируется при выполнении) |
| `PRINTF` | Вывод значений регистров `F0`..`F9` в отладочный лог SEGGER RTT |

#### Условные переходы (`IF`, `ELSE`, `ENDIF`)
* В `IF` слева указывается только регистр (`F0..F9`), справа — число или регистр. Поддерживаются операторы: `<`, `<=`, `>`, `>=`, `==`, `!=`.
* Дробные числа рекомендуется сравнивать через `>=` и `<=`, так как точное равенство `==` может не сработать из-за погрешностей округления `float`.
* Допускается вложенность блоков `IF` в `IF` (допустимы вложенные `ELSE` и `ENDIF`).

#### Как работают подпрограммы (`GOSUB` и `RET`)

Команды **`GOSUB`** (*Go to Subroutine*) и **`RET`** (*Return*) позволяют вынести повторяющийся кусок кода в отдельный блок (подпрограмму), вызывать его из разных мест скрипта и **автоматически возвращаться обратно** на следующее действие.

* **В чём разница между `GOTO` и `GOSUB`**:
  * `GOTO 10` — безусловный переход «в один конец». Контроллер просто прыгает на строку 10 и забывает, откуда пришёл.
  * `GOSUB 10` — переход «с закладкой». Контроллер запоминает номер строки, следующей за `GOSUB`, и только потом переходит на строку 10.
  * `RET` — возврат. Контроллер смотрит в сохранённую закладку и возвращается ровно туда, откуда была вызвана подпрограмма.

**Пошаговый пример работы**:
Скрипт подаёт сначала короткий импульс (100 мс), затем длинный (500 мс), используя одну и ту же подпрограмму на строках 6–9:

```text
1  LOAD F0 100
2  GOSUB 6
3  LOAD F0 500
4  GOSUB 6
5  END
6    CH1 CR ON
7    DELAY F0
8    CH1 CR OFF
9    RET
```

| Шаг | Строка | Команда | Что делает контроллер |
|:---:|:---:|:---|:---|
| 1 | `1` | `LOAD F0 100` | Записал 100 мс в регистр `F0` |
| 2 | `2` | **`GOSUB 6`** | **Запомнил возврат: строка 3.** Перешёл на строку `6` |
| 3 | `6` | `CH1 CR ON` | Включил выход |
| 4 | `7` | `DELAY F0` | Ждёт 100 мс (значение из `F0`) |
| 5 | `8` | `CH1 CR OFF` | Выключил выход |
| 6 | `9` | **`RET`** | **Вспомнил возврат: вернулся на строку 3!** |
| 7 | `3` | `LOAD F0 500` | Записал 500 мс в регистр `F0` |
| 8 | `4` | **`GOSUB 6`** | **Запомнил возврат: строка 5.** Снова перешёл на строку `6` |
| 9..11 | `6..8` | *импульс* | Включил выход, подождал 500 мс, выключил выход |
| 12 | `9` | **`RET`** | **Вспомнил возврат: вернулся на строку 5!** |
| 13 | `5` | `END` | Скрипт завершил работу |

> [!IMPORTANT]
> **Два главных правила работы с подпрограммами**:
> 1. **Обязательно отделяйте подпрограммы командой `END` или `GOTO`** (как на строке 5 в примере). Микроконтроллер выполняет строки сверху вниз: если перед подпрограммой не поставить `END`, скрипт сам въедет в неё, дойдёт до `RET`, не найдёт точки возврата и остановится с ошибкой **STOP**.
> 2. **Выходите из подпрограммы только по `RET`, а не по `GOTO`**. Адреса возврата сохраняются в стек (до **4 уровней** вложенности). Если вместо `RET` выйти через `GOTO`, уровень стека останется занятым, и после 4 таких выходов скрипт завершится аварийной остановкой.

## 4. Примеры скриптов

### Набор начальных настроек (`load_def.txt`)
```text
T Default
CR1 FR 1000
CR1 MOD 01_SINE_12b
CH1 CR ON
AM1 FR 10.4
AM1 MOD 01_SINE_12b
CH1 AM OFF
FM1 BASE 2500
FM1 DEV 200
FM1 FR 10.5
FM1 MOD 01_SINE_12b
CH1 FM OFF
END
```

### Линейный свип частоты
Перестройка частоты от 200 до 5000 Гц с шагом 50 Гц каждые 100 мс (полный цикл ~10 секунд):
```text
LOAD F1 200
CR1 FR F1
DELAY 100
PLUS F1 50
IF F1 <= 5000
GOTO 2
ENDIF
GOTO 1
```

### Логарифмический свип
Каждый шаг умножает частоту на 1.02, перестройка от 200 Гц до 10 кГц:
```text
LOAD F1 200
CR1 FR F1
DELAY 50
MUL F1 1.02
IF F1 < 10000
GOTO 2
ENDIF
GOTO 1
```

### Пачка импульсов
Пять импульсов по 100 мс, затем 1 секунда паузы:
```text
LOAD F0 5
CH1 CR ON
DELAY 100
CH1 CR OFF
DELAY 100
MINUS F0 1
IF F0 > 0
GOTO 2
ENDIF
DELAY 1000
GOTO 1
```

### Смена форм сигнала каждые 2 секунды
```text
CH1 CR ON
CR1 MOD 01_SINE_12b
DELAY 2000
CR1 MOD 13_TRIAGLE
DELAY 2000
CR1 MOD 14_Square
DELAY 2000
GOTO 2
```

### Пошаговые измерения с подтверждением (`WAIT`)
Скрипт переключает частоту и ждёт клика пользователя для снятия показаний:
```text
LOAD F1 200
CR1 FR F1
WAIT
PLUS F1 100
IF F1 <= 5000
GOTO 2
ENDIF
END
```

### Подпрограмма с параметром и цикл `LOOP`
Генерация трёх коротких импульсов и одного длинного:
```text
LOAD F1 3
LOAD F0 100
GOSUB 9
LOOP F1 2
LOAD F0 500
GOSUB 9
DELAY 1000
GOTO 1
CH1 CR ON
DELAY F0
CH1 CR OFF
DELAY 100
RET
```

## 5. Обработка ошибок

При возникновении синтаксической или логической ошибки скрипт останавливается на соответствующей строке:
* Неизвестная команда (например, `GOT 5`);
* Обращение к несуществующему регистру (`PLUS F10 5`);
* Пропущен операнд (`CR1 FR`);
* Некорректный оператор сравнения (`IF F1 = 2`);
* Деление на ноль (`DIV F1 F2` при `F2 == 0`);
* Нарушение структуры блоков: `IF` или `ELSE` без `ENDIF`;
* `RET` без предварительного `GOSUB`, либо превышение глубины вложенности `GOSUB` (> 4);
* Неизвестный параметр в `READ` (`READ F1 CR1 MOD`);
* Переход на несуществующую строку или отсутствие аргумента в `GOTO`.

> [!IMPORTANT]
> Для диагностики откройте экран **«Скрипт вид»**: в статусе будет отображено **STOP**, а ошибочная строка будет подсвечена.

Не приводят к аварийной остановке:
* Опечатка во втором слове команды (`CR1 XX 5` игнорируется);
* Нечисловое значение (`CR1 FR abc` установит 0 Гц);
* Указание отсутствующего файла формы (скрипт продолжит работу, но форма сигнала не сменится).

## 6. Временные характеристики и точность

* Команда `DELAY` отсчитывает системные миллисекунды (`HAL_GetTick()`), однако фактическое обновление сигнала на ЦАП привязано к DMA-буферу (период буфера ~4.1 мс).
* Перерисовка кадра дисплея занимает ~40 мс; во время передачи кадра скрипт ждёт завершения DMA экрана.
* Главный экран генератора обновляется от команд скрипта с частотой до 5 раз в секунду, экран «Скрипт вид» — до 20 раз в секунду.
* Из-за этого шаги короче 50 мс могут иметь джиттер.
* Если требуется формирование высокоточных коротких импульсов, используйте режим AM с формой `14_Square`: модуляция синтезируется с точностью до отсчёта ЦАП (~2 мкс).

## 7. Редактор на устройстве

Вход в редактор: пункт **«Редактор»** в меню настроек или **длительное удержание** кнопки энкодера в окне **«Скрипт вид»**.

### Управление в редакторе

| Действие | Результат |
|---|---|
| **Поворот энкодера** | Перемещение курсора по строкам |
| **Клик по строке** | Контекстное меню строки: *Вставить выше*, *Вставить ниже*, *Изменить*, *Копия*, *Переместить*, *Удалить*, *Назад* |
| **Клик по «+ в конец»** | Добавление новой команды в конец файла |
| **Длительное удержание** | Главное меню редактора: *Назад*, *Запуск*, *Стоп*, *Сохранить*, *Сохранить как*, *Новый*, *Открыть*, *Выход* |

* Команда составляется поблочно: сначала выбирается функциональный блок, затем аргументы.
* Команды `MUL`, `DIV`, `WAIT`, `LOOP`, `GOSUB`, `RET` и `READ` сгруппированы в пункте «Еще».
* Числа вводятся поразрядно: поворот меняет цифру, клик переключает разряд, длительное удержание подтверждает ввод.
* При вставке, удалении или перемещении строк **номера переходов в `GOTO`, `GOSUB` и `LOOP` пересчитываются автоматически**.
* Перед запуском и сохранением валидатор проверяет парность `IF / ELSE / ENDIF`, корректность переходов и автоматически дописывает команду `END`, если она отсутствует.
* В окне редактора (как и в «Скрипт вид») строки внутри блоков `IF / ELSE / ENDIF` и подпрограмм `GOSUB` автоматически отображаются со смещением вправо (отступ 1 символ), наглядно показывая структуру кода.

## 8. Совместимость с версией для Android

В приложении [GeneratorAndroid](https://github.com/Sacamoto84/GeneratorAndroid) используется схожий язык, однако файлы напрямую не взаимозаменяемы:
* На Android используется расширение `.sk` (вместо `.txt`);
* Нумерация строк в `GOTO` на Android начинается с нуля (на устройстве — с 1);
* В Android-версии отсутствуют команды: `T`, `YIELD`, `PRINTF`, `MUL`, `DIV`, `WAIT`, `LOOP`, `GOSUB`, `RET` и `DELAY F<n>`.
